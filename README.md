# 心有灵犀 · Kindred

两个人各写一个词，同时揭晓；下一轮根据上一轮的两个词继续联想，直到两人写出**同一个词**。

*Two minds, wandering word by word, until they meet.*

- 两人远程实时对战，发个链接就能玩
- 每轮限时：30 秒 / 60 秒 / 不限时（时间到会自动提交输入框里的内容）
- 每轮同时揭晓两人的词，所有轮次都保留展示；写出同一个词时两张卡片会合二为一
- **中文 / English 随时切换**，每位玩家各自选择，互不影响；中英文的词都可以写，也可以混着写
- 英文判定很宽容：忽略大小写、冠词、重音和简单复数（`Stars` = `star`，`The Moon` = `moon`）
- 默认不能写已经出现过的词（房间里可关闭）
- 刷新、断网、切后台都能自动恢复进度；换手机可以"认领"自己的座位；第三个人打开链接可以观战
- 自带字体（思源宋体 + Fraunces），在 iPhone、安卓、Windows、Mac 上看起来完全一致
- 手机优先设计，自动适配深色模式

纯静态网站，**不需要服务器、不需要注册任何服务**，直接放到 GitHub Pages 就能用。

## 部署 / 更新到 GitHub Pages

所有文件都在同一层，没有子文件夹。

1. 打开你的仓库，点 **Add file → Upload files**。
2. 把这个文件夹里的**所有文件**一起拖进去（同名文件会被直接覆盖），点 **Commit changes**。
   - `.nojekyll` 是隐藏文件，传不上也没关系。
3. 第一次部署的话：进入 **Settings → Pages**，Branch 选 **main** 和 **/(root)**，点 **Save**。
4. 等 1～2 分钟刷新网页即可。

> 想自己先试试？同一个浏览器开两个标签页，用不同名字分别创建 / 加入即可。

## 原理 & 隐私

GitHub Pages 只能放静态网页，所以两人之间的实时同步借助了**公共 MQTT 服务器**（EMQX、HiveMQ 提供的免费 WebSocket 服务）转发消息：

- 页面会**同时连接两个服务器**，任意一条线路通就能玩，一个挂了另一个顶上。
- 所有游戏内容在浏览器里用**房间号派生的密钥加密**（PBKDF2 + AES-GCM），服务器和其他人只能看到乱码。
- 进度保存在服务器的"保留消息"和你自己浏览器的本地存储里，任意一方刷新都能恢复；服务器重启丢了数据也会被自动补回。

### 换成自己的服务器（可选）

编辑 `config.js` 里的 `brokers` 列表即可，任何支持 **MQTT over WebSocket (wss://)** 的服务器都行。

## 常见问题

**一直显示"连接中"？** 公共服务器偶尔会抽风或被所在网络拦截。换个网络试试，或在 `config.js` 里加一个新的服务器地址（两人要用同一份配置）。

**微信里打不开？** 点右上角 **···** → **在浏览器打开**。

**换了手机怎么继续？** 用同一个链接打开，会看到"房间已满"，点 **我是 XXX** 就能接着玩。

**本地预览**：需要用本地服务器打开（加密功能要求安全环境）：

```bash
python3 -m http.server 8080   # 然后打开 http://localhost:8080
```
